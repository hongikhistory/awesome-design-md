# 널리잇다 최종 방향과 기능 확정 (2026. 11. 26.)

## 1. 대회 안내문에서 확인한 조건

| 항목 | 안내문 내용 | 널리잇다에 주는 의미 |
|---|---|---|
| 주제 | 수업에 활용할 수 있는 교육용 웹콘텐츠(자유 주제). 예: 개념 탐구·시각화, **형성평가·문제 생성기**, 학습 게임, 수업 보조 챗봇, **모둠 편성·자리 배치 같은 학급 운영 도구** | 교사 행정 도구만으로는 ‘수업 활용’이 약하다. 학생이 수업 중에 쓰는 결과물이 있어야 한다. |
| 심사 | 교육적 가치, 아이디어 창의성, 내용 전개의 논리성, 매체 활용의 적절성, 콘텐츠 완성도(각 10점) | 학생 화면과 수업 흐름(준비 → 활동 → 기록)을 보여 줘야 논리성·매체 활용 점수를 받는다. |
| 심사 방법 | 심사위원이 제출 링크에 직접 접속해 실행 | 처음 화면(온보딩)에서 1분 안에 핵심을 보여 줘야 한다. |
| 참가 | **개인 참가만 가능** | 발표·문서의 ‘팀’ 표현을 없앤다. |
| 제출 | 1차(11. 6.) → 워크숍 피드백 → **최종(11. 27.)**, 링크는 12. 18.까지 로그인 없이 공개, 2~3분 시연 영상 권장 | 공개 배포 주소가 필요하다(claude.ai 링크는 비공개). |
| 유의 | 가상 데이터만, API 키 노출 금지 | 이미 지킨다(가상 홍익중학교, 외부 API 없음). |

1차 산출물은 고등학교 한국사 사료 탐구 활동 **「이 사건의 이름은?」**이었다(사료 5편 → 출처 비판 → 근거 분류 판단판 → 이름 결정 → 반론 카드). 최종 결과물이 1차와 이어진다는 점이 드러나야 한다.

## 2. 최종 방향

> **널리잇다: 선생님의 수업 준비부터 수업 활동, 기록까지 잇는 교사용 웹콘텐츠**

1차 작품에서 얻은 “근거를 따져 판단하는 학생 활동”을 **어느 교과에서나 교사가 몇 줄로 만들 수 있게** 넓히고, 그 앞뒤의 수업 준비(지도안·슬라이드·모둠)와 기록(누가기록·생기부)을 잇는다. 행정 도구(통신문·결강)는 ‘수업 밖 시간을 줄여 수업 준비로 돌린다’는 이유로 남기되 발표 비중은 줄인다.

수업 한 차시의 흐름이 곧 시연 동선이다.

1. **준비:** 지도안(HWP) → 문서 변환 → 수업 슬라이드
2. **활동:** 학생 활동 만들기(확인 문제·근거 판단·출구 카드) → 학생 휴대폰 → 모둠·자리
3. **기록:** 출구 카드·관찰 → 누가기록 → 세특 점검
