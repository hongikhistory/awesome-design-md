# 현장 자료 조사와 반영 내역 (4차)

교육청·교육부 자료와 중·고등학교 교사용 지침을 조사해 널리잇다에 반영했다. 조사일은 2026. 11. 26.이다.

## 조사 방법과 한계

- 공개 웹 자료만 썼다. 교육부, 시·도교육청, 개인정보보호위원회, 국립국어원 자료를 우선했고, 언론 보도는 보조 근거로만 썼다.
- 조사 환경에서 대부분의 go.kr 원문 PDF를 직접 열 수 없었다. 아래 내용은 검색 결과 발췌로 확인한 것이므로, 학교에서 쓰기 전에 원문 쪽수와 대조해야 한다.
- 태그 뜻: **[공식]** 공식 문서 발췌로 확인, **[보도]** 언론이나 2차 해설 자료, **[불확실]** 출처끼리 다르거나 확인하지 못함.
- 앱 화면도 같은 기준을 따른다. 생기부 점검 결과와 글자 수 한도에는 ‘기재요령 확인 / 원문 대조 필요 / 관례’ 표시가 함께 붙는다.

## 5. 아직 하지 못한 것

- **원문 대조:** 2026 기재요령(중·고) 원문 PDF를 쪽수 단위로 대조하지 못했다. 학교 배포 전에 한 번 더 확인해야 한다.
- **상담 기록 기준:** 상담 일지의 표준 항목과 보존 기간은 공식 자료에서 찾지 못했다. 그래서 앱은 구분(정기·수시·위기·추수), 대상, 방식, 영역, 내용, 후속 조치, Wee클래스 연계만 기록한다.
- **항목 기호 자동 점검:** 1. → 가. → 1) 순서를 자동으로 점검하는 기능은 넣지 않았다.
