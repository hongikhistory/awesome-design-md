# AI Bootcamp

AI 스터디 부트캠프 — Claude Code를 활용한 4주 완성 AI 서비스 개발 챌린지. Figma-inspired black-and-white interface with vibrant multi-color gradient accents.

## Design Characteristics

- Strictly monochrome interface (pure black and white)
- Figma-inspired multi-color gradient hero (green, purple, orange, blue)
- Pill-shaped buttons and badges (50px radius)
- Noto Sans KR + Space Mono typography pairing
- Animated gradient backgrounds
- Gallery-like section pacing
- Korean-first bilingual content
